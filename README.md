# Ступени к сцене

Тренажёр по сольфеджио для учеников музыкальной школы.

Открывается в браузере, ничего устанавливать не нужно, регистрации нет.

**Играть:** https://dzhuskirill.github.io/solfedzhio/

## Что внутри

Три уровня сложности — 1–3, 4–5 и 6–7 класс. Маршрут из станций, на каждой
пять заданий:

- чтение нот на стане, скрипичный и басовый ключ;
- буквенные обозначения и тональности (немецкая система: си — H, си-бемоль — B);
- знаки при ключе;
- интервалы;
- аккорды: трезвучия и обращения;
- ступени лада: главные трезвучия в тональности;
- слух: интервалы, аккорды и ноты от опорного звука.

Есть отдельный режим тренировки по одной теме.

## Про точность

Ответы не записаны готовым списком, а вычисляются по правилам: тональности —
из круга квинт, интервалы — из ступеней и полутонов, аккорды — из формул.
Расчёт сверен с таблицами из учебника сольфеджио.

Страница самодостаточна: нотная библиотека вшита внутрь файла.
